# Gold Price Prediction Using Machine Learning

A comprehensive Flask web application for predicting gold prices using machine learning algorithms. The application uses 10 years of historical data (2016-2026) and provides accurate predictions with confidence intervals.

## Features

- **ML-Powered Predictions**: Uses XGBoost, Random Forest, and Gradient Boosting algorithms
- **10-Year Dataset**: Comprehensive historical data with realistic market events
- **95% Confidence Intervals**: Provides upper and lower bounds for predictions
- **Interactive Visualizations**: Dynamic charts using Plotly
- **Technical Indicators**: RSI, MACD, Bollinger Bands, and moving averages
- **Export Functionality**: Download predictions in CSV format
- **Responsive Design**: Works on desktop and mobile devices

## Technology Stack

- **Backend**: Python, Flask
- **ML Libraries**: Scikit-learn, XGBoost
- **Data Processing**: Pandas, NumPy
- **Visualization**: Plotly
- **Frontend**: HTML5, CSS3, Bootstrap 5, JavaScript
- **Model Persistence**: Joblib
