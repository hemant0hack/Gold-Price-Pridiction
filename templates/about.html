About Gold Price Predictor

Gold Price Predictor is an advanced machine learning application designed to forecast gold prices with high accuracy. Using state-of-the-art algorithms and 10 years of historical data, it provides reliable predictions for investors and analysts.

Key Features

  • ML-Powered Predictions: Uses XGBoost, Random Forest, and Gradient Boosting algorithms
  • 10-Year Dataset: Comprehensive historical data from 2016-2026 with realistic market events
  • 95% Confidence Intervals: Provides upper and lower bounds for predictions
  • Interactive Visualizations: Dynamic charts using Plotly for better insights
  • Technical Indicators: RSI, MACD, Bollinger Bands, and moving averages
  • Export Functionality: Download predictions in CSV format

Technology Stack

Python 3.9+ Flask Scikit-learn XGBoost Plotly Pandas NumPy Bootstrap 5

How It Works

1. Data Generation

Synthetic but realistic gold price data with trends, seasonality, and major economic events.

2. Feature Engineering

Technical indicators, lag features, rolling statistics, and market indicators.

3. Model Training

Multiple ML models trained on 80% of data with hyperparameter tuning.

4. Prediction

Future prices predicted with confidence intervals for up to 90 days.
